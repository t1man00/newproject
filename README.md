Учебный репозиторий в рамках курса по Fullstack AI Development. Здесь отрабатывается базовый рабочий процесс с Git и GitHub.

## Что внутри

- `README.md` — описание проекта
- `.gitignore` — список файлов, которые Git не отслеживает
- `LICENSE` — лицензия MIT

## Рабочий процесс

1. Изменения делаются в ветке `dev` (в том числе с помощью Claude Code).
2. Из `dev` открывается pull request в `main`.
3. После проверки pull request сливается через сайт GitHub.
